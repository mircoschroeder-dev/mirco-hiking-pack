# Wanderrucksack aufs Handy bringen

1. Die Datei liegt hier im Projektordner: `Wanderrucksack-v0.5-2026-11-20.apk`
2. Bring sie per USB-Kabel, Cloud-Ordner oder Messenger aufs Handy.
3. Tippe sie auf dem Handy an. Android fragt einmalig, ob die Datei-App Apps installieren darf. Erlaube das.
4. Neue Versionen installierst du einfach ueber die alte. Deine Listen bleiben dabei erhalten.

Wichtig: Das Drueberinstallieren klappt nur, wenn die neue Version auf diesem Rechner gebaut wurde.
Die App ist mit dem Debug-Schluessel dieses PCs signiert (`%USERPROFILE%\.android\debug.keystore`). Diese Datei also nicht loeschen.
